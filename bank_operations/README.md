# Приложение для анализа банковских операций

Курсовая работа: приложение читает транзакции из Excel/CSV и готовит JSON для страниц, сервисы поиска и Excel/JSON отчеты.

## Что умеет программа

- страница **Главная**: приветствие, карты, топ-5 операций, курсы валют, акции
- страница **События**: расходы, поступления, топ-7 категорий, переводы и наличные
- сервисы: выгодные категории кешбэка, инвесткопилка, поиск, телефоны, переводы физлицам
- отчеты: траты по категории, по дням недели, в рабочий/выходной день

## Установка

```text
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Если пользуетесь Poetry:

```text
poetry install
```

Скопируйте `.env_template` в `.env`, если хотите поменять адреса API.

Файл операций положите в `data/operations.xlsx` (или `.xls` / `.csv`).
Если файла нет, программа сама скачает таблицу по ссылке из задания.

Ссылка на данные: https://docs.google.com/spreadsheets/d/1yXnr282zAMcTkEhIwZFaJlPJvAeZIwvB/edit?usp=sharing

## Запуск

```text
python -m src.main
```

## Настройки

Файл `user_settings.json`:

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```

Курсы валют берутся с `https://www.cbr-xml-daily.ru/daily_json.js`.
Цены акций — Yahoo Finance. Если API не ответил, подставляются запасные значения больше нуля, чтобы страница все равно собралась.

## Как считаются данные

- для Главной и Событий берутся операции со статусом OK
- период по умолчанию: с 1 числа месяца по указанную дату
- для Событий можно передать `W`, `M`, `Y` или `ALL`
- кешбэк по карте: 1 рубль на каждые 100 рублей расходов
- выгодные категории: 1% от суммы трат по категории за месяц
- поиск не смотрит на регистр и ищет и в описании, и в категории
